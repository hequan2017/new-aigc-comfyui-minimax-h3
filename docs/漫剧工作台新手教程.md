# ComfyStudio 漫剧工作台 · 新手教程

> 跟着本教程，零基础做出一部完整的漫剧短片（约 30–60 秒，6–10 个分镜，含角色、画面、视频、配音、字幕、成片）。
>
> 平台地址：http://<服务器IP>:18000

---

## 🧭 整体流程（8 步）

```
新建项目 → 创作方案(自动出角色) → 角色标准像(锁人物)
       → 剧本(含对白) → 分镜画面 → 场景视频
       → 配音+字幕 → 合并成片
```

项目详情页顶部的**步骤条**会显示你进行到哪一步（方案 → 角色标准像 → 画面 → 视频 → 合并），跟着它走即可。

> 💡 也可以直接点「一键生成全片」让系统自动跑完第 2–8 步（约 10–20 分钟）。但建议新手先手动走一遍，理解每步产出。

---

## ✅ 第 0 步：前置准备（只需做一次）

### 0.1 平台设置
顶部导航 → **平台设置**，填写：
- **API Key**：火山引擎方舟 API Key（[控制台获取](https://console.volcengine.com/ark)）
- **文生文模型**：`deepseek-v4-flash-260425`（剧本生成）
- **文生图模型**：`doubao-seedream-5-0-260128`（画面/标准像）
- **TTS 模型**：`doubao-tts`（配音，可选）
- **默认音色 voice_type**：填一个豆包音色 ID（配音用，不配音可留空）

填完点 **保存配置**，再点 **测试文生文 / 测试文生图** 确认连通。

### 0.2 确认实例可用
顶部导航 → **总览**，确认 8 个 comfyui 实例状态为 **running**（视频生成靠它们）。
- 若显示 stopped：去 **实例管理** → 一键启动（或服务器执行 `bash /opt/comfyUI/start-multi-gpu.sh start`）

---

## 📝 第 1 步：新建项目

1. 顶部导航 → **漫剧工作台** → 右上角 **新建项目**
2. 填写：
   - **故事创意**（必填）：一句话或一段话。例：*一位退休列车司机在末班车上发现乘客都是已故之人，他决定查明真相。*
   - **画幅**：选 **竖屏 9:16**（短剧/抖音/快手推荐）或 横屏 16:9
   - 题材/画风/受众/基调/结局/集数：可选，填得越具体，方案越贴合
3. 点 **创建项目** → 自动进入项目详情页

---

## 🎭 第 2 步：生成创作方案（自动产出角色）

1. 项目详情页右上角 → **生成创作方案**
2. 等待约 30–60 秒（调用文生文）
3. 产出（展开「创作方案」卡片查看）：
   - **剧名 / 一句话故事线 / 三幕结构**
   - **主要角色**（含外貌 trait、服装 style）
   - **分集目录**（每集标题 + 剧情提示词，可编辑）
   - 同时**自动抽取角色卡**到「角色与人物」区块

> ✅ 步骤条第 1 步「创作方案」变亮。

---

## 🧑‍🎨 第 3 步：生成角色标准像（关键：锁定人物）

> ⚠️ **这一步很重要**：先有角色标准像，后续视频才能用 ref2v 锁定人物形象，避免同一角色在不同镜头里长得不一样（风格漂移）。

1. 滚动到 **角色与人物** 区块
2. 点 **一键生成标准像 (N)**（N = 还没生成标准像的角色数）
3. 等待每个角色头像生成（约 10 秒/个，限流并发）
4. 角色卡出现头像 ✅

> ✅ 步骤条第 2 步「角色标准像」变亮。可点单个角色卡编辑 trait/style 后重新生成。

---

## 📜 第 4 步：生成剧本（含对白）

1. 右上角 → **重新生成剧本**
2. 等待约 30–60 秒
3. 产出（当前集）：
   - **分镜场景**（6–10 个，每个 3–8 秒）
   - 每个场景含：画面提示词、视频提示词、**对白/旁白**（用于配音和字幕）

> 可在「剧本」区块编辑剧本正文后点「保存并 AI 重新生成分镜」重做。

---

## 🖼️ 第 5 步：生成分镜画面

1. 滚动到 **场景工作区**（当前集）
2. 点 **生成该集全部画面 (N)**
3. 等待文生图（约 30 秒/张，已按画幅比例生成、自动注入角色设定）

> ✅ 步骤条第 3 步「分镜画面」变亮。每张画面可单独「重新生成」。

---

## 🎬 第 6 步：生成场景视频

1. 点 **生成该集全部视频 (N)**
2. 等待（每个 3–8 秒视频约 60–120 秒）：
   - 有角色标准像 → 自动用 **ref2v** 锁定人物
   - 无角色 → 用 i2v（更快）
3. 进度实时显示在场景卡（节点级百分比）

> ✅ 步骤条第 4 步「场景视频」变亮。失败会自动重试 2 次。

---

## 🎤 第 7 步：对白配音 + 字幕（可选）

1. 右上角 **🎤 一键配音** → 合成所有对白（需第 0 步配了 TTS 音色）
2. 场景卡对白行可点 ▶ 试听
3. 右上角 **📜 下载字幕** → 下载该集 SRT 字幕文件

> 未配 TTS 音色时会提示「未配置 TTS 音色」，不影响其他流程；视频照常生成，只是没配音。

---

## ✂️ 第 8 步：合并成片

1. 滚动到 **合并成片** 区块
2. 点 **⚡ 合并第 N 集**（当前集）或 **🎬 整剧一键合并**（所有集）
3. 等待 ffmpeg 拼接（约 10–30 秒）
4. 合并完成 → 出现成片视频，可在线预览 / 下载

> ✅ 步骤条第 5 步「合并成片」变亮，项目状态变为「成片完成」。

🎉 **完成！** 你已经做出一部带角色一致性、配音、字幕的漫剧短片。

---

## ⚡ 一键生成全片（进阶）

不想逐步点？项目详情页右上角 → **一键生成全片**，系统自动按顺序执行：
方案 → 角色标准像 → 剧本 → 画面 → 视频 → 配音 → 合并成片。

整个流程约 10–20 分钟（取决于场景数和 GPU 负载），期间可关闭页面，后台持久化执行，服务重启也能恢复。

---

## 🆘 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 保存图片失败 / ssh handshake | 实例未运行 → 总览页启动实例，或服务器 `bash /opt/comfyUI/start-multi-gpu.sh start` |
| 视频里人物不一致 | 跳过了第 3 步「角色标准像」→ 先生成标准像，再重新生成视频 |
| 配音失败「未配置 TTS 音色」 | 平台设置里填「默认音色 voice_type」 |
| 一键生成卡在某步 | 看项目详情顶部红色错误提示；单步重试 |
| 想换画幅（横↔竖） | 编辑项目信息改画幅 → 需重新生成画面和视频（旧产物比例不一致） |

---

## 📚 多集制作

- 创作方案的「分集目录」可编辑每集标题/剧情提示词
- 项目详情按集切换（第 N 集），每集独立生成场景、画面、视频、合并
- 字幕/合并都按集产出

祝创作顺利！🎬
