# 漫剧平台对标分析与优化建议

> 日期：2026-08-06
> 范围：ComfyStudio（ComfyUI 多卡管理 + AI 漫剧工作台）对标主流漫剧/AI短剧平台，输出优化建议与可新增功能清单
> 性质：意见文档，不涉及代码改动

---

## 1. 现状盘点

### 1.1 已有能力（相对优势）

| 模块 | 能力 |
|---|---|
| GPU 调度 | 8×L40 实例管理、负载探测、最空闲 GPU 自动调度 |
| 任务流水线 | 模板化任务（t2v/i2v/首尾帧/ref2v）、WS 节点级进度、失败重试、崩溃恢复 |
| 漫剧流水线 | 剧本→分镜画面→场景视频→合并成片的持久化状态机 |
| 创作方法论 | 集成 short-drama（三幕/节奏曲线/付费卡点/爽感矩阵/四层反派） |
| 角色资产 | Character Bible：角色卡、标准像、按场景出场角色注入权威设定 |
| 部署 | 单二进制 + Docker + CDI 绑卡，远程 SSH/SFTP 双模式 |

### 1.2 关键短板

- **无竖屏 9:16 分辨率预设**（漫剧标配横竖屏，当前只有横屏 832×480 / 1280×704 / 1920×1088）
- **角色一致性只做到"文本注入"**，无图像参考约束（IP-Adapter/InstantID/ref2v 参考图）
- **无配音/TTS、无字幕、无口型同步**
- 成片合并为裸 concat，无转场/切集/片头尾
- 无用户/权限、无成本与用量统计

## 3. 优化建议（按优先级）

### P0 高优先（差距大、投入产出比高）

1. **竖屏 9:16 分辨率预设**
   - 新增 720×1280（720P 竖）/ 1080×1920（1080P 竖）预设
   - MiniMax H3 支持竖屏比例，仅需模板 `width/height` 占位符 + 前端预设列表

2. **角色一致性升级：图像参考路线**
   - i2v 首帧模式改为 ref2v 并注入角色标准像（`Portrait` 已生成，只差工作流接线）
   - 或 ComfyUI 加 IP-Adapter / InstantID 节点做推理时人脸锁定
   - 学习 CineGen「定妆照+衣橱系统」：一角色多造型（现代装/古装/病号服），面部一致

3. **配音 TTS（spec 阶段 2 落地）**
   - 火山 TTS（已有 Ark 密钥）逐场景对白/旁白合成 → mux 进场景视频音轨
   - 音色分配：按角色分配固定音色（voice_assigner 思路），需解决性别/年龄匹配
   - 参考 `cyuanxv/ai-mandrama-skills` 的 edge-tts 声线+情绪 rate/pitch 表、ffmpeg adelay/amix 混音模板

4. **字幕能力**
   - Whisper ASR 转写 → 烧录字幕（FFmpeg drawtext）或导出 SRT
   - 出海时用 Netflix 级 CPS/行长校验（参考 subtitle-dubbing-localization-agent-skill）

### P1 中优先（显著提升成片质量/生产效率）

5. **分镜升级**
   - 单场景多候选帧（grid 生成→切分，改图成本=改视频的 1/18）
   - 关键帧驱动：起帧+止帧→插值（对应已有 first_last 模板，可复用）
   - 运镜提示词：3D 相机控制（俯视/仰视/推拉）自动生成（comfyui-storyboard 思路）

6. **成片后处理**
   - 转场、节奏裁剪、片头片尾模板
   - 按平台规格自动切集（每集 1-3 分钟、前 3 秒钩子），红果/抖音比例 9:16

7. **多引擎适配器**
   - MiniMax/Seedance/Kling/Vidu 可插拔 + 失败自动切换竞赛（开源标配）
   - 现有模板机制（`{{param}}` 占位符 + JSON 模板）已支持扩展，成本低

8. **交付中心（spec 阶段 3）**
   - 按项目/集聚合成片、分镜图、角色像，版本管理 + 批量下载

### P2 低优先（锦上添花）

9. 登录/权限（目前无认证，内网可暂缓）
10. 数据统计：token 成本、GPU 利用率、单集耗时、成功率
11. 首页叙事重设计（spec 阶段 4，参考灵映产品理念首页）
12. 出海本地化：剧本 `/overseas` 模式已有，补字幕翻译+多语言配音
13. 安全：`remote.password` 明文在 config.yaml，改环境变量/key 文件

## 5. 建议路线图

```
阶段 A（1-2 周）     阶段 B（2-4 周）          阶段 C（4-8 周）
┌──────────────┐   ┌──────────────────┐   ┌──────────────────────┐
│ 竖屏 9:16 预设│   │ TTS 配音+音轨 mux │   │ 出海本地化（字幕翻译/配音）│
│ 角色像接 ref2v │   │ 字幕 ASR+烧录      │   │ 多引擎适配器+竞赛      │
│ drama-skills  │   │ 分镜多候选帧+关键帧 │   │ 交付中心+统计         │
│ 接入           │   │ 成片转场/切集      │   │ 登录/权限             │
└──────────────┘   └──────────────────┘   └──────────────────────┘
```

**结论**：平台差异化竞争点在「角色一致性 + 全链路自动化」。当前项目工程底座（调度/恢复/状态机）已超过多数开源项目，补齐「竖屏 → 图像锁角色 → 配音 → 字幕 → 成片后处理」即可形成完整交付闭环。
